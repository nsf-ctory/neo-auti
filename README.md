# Auti.

**Nem toda conversa precisa começar com uma pergunta.**

Há dias em que explicar é demais.  
Em que encontrar as palavras já é trabalho suficiente.  
Em que o silêncio também tem alguma coisa a dizer.

A Auti. nasce desse intervalo.

Não para corrigir pessoas.  
Não para ensinar alguém a parecer diferente.  
Mas para abrir espaço a uma conversa que não exige performance.

**Seu ritmo não é um problema a resolver.**
